# 日本語テックライトの書き分け

更新日: 2026-08-21

この文書はQ Atlantisの公開サイト向け適用規約です。横断正本はZeroRoomLab-manifestの
[日本語テックライト語形レジスタ](https://github.com/saitoomituru/ZeroRoomLab-manifest/blob/main/docs/operations/japanese-technical-writing-word-form-register.ja.md)
に置きます。

## 読者を技術語で選別しない

Q Atlantisは、オカルト、スピリチュアル、信仰、ゲーム、創作、工学の読者が同じ入口を使います。
英字の多さを技術の権威として振りかざさず、一般の説明は日本語を既定にします。

ただし、世界観の演出として意図した短い英字、機械識別子、コマンド、パス、API、既存製品名は原表記を
保てます。トップ画面の`WORLD`や`OPEN REFORGE`は演出、`schema_version`や`git push`は機械境界です。
本文へ理由なく英単語を散らすこととは区別します。

近年の英語圏テンプレートやAI生成文を直に戻し、`documentation`、`guide`、`manual`、`tutorial`、
`reference`を全部「ドキュメント」へ丸めません。問題は海外由来であることではなく、媒体の責務差を読まず、
「グローバル標準らしさ」の演出として逆輸入することです。

## 役割で書き分ける

| 対象 | Q Atlantisでの表記 | 境界 |
|---|---|---|
| 構造を設計する人・作用 | スキーマー | 成果物のスキーマと混ぜない |
| 出来上がった構造定義 | スキーマ | 実在パスは`schema/`のまま |
| 機械による描画工程 | レンダー | 人間の目視確認とは別 |
| プログラム成果物の操作部品 | GUI | 人が見る対象は画面 |
| 人間が見え方を設計する工程 | 画面デザイン | GUI実装済みと同義ではない |
| 汎用概念としての能力・手順束 | スキル | OpenAI等の固有実装名や`SKILL.md`は原表記を保てる |
| 人間向けのGit作業面 | ワークツリー | コマンドは`git worktree` |
| 公開環境へ反映する工程 | デプロイ | スクリプト名や機械tokenの`deploy`は保持 |
| 人間向けの検証 | 試験 | `tests/`、`npm test`等は保持 |

例えば「コックピットGUIのレンダー・境界自動試験18件が成功した」と
「実画面の目視確認が終わった」は別の主張です。前者から後者を推定しません。

## 説明書、教本、資料、リファレンス

- **ドキュメント**: 記録された説明物の総称。用途によって説明書、教本、資料、リファレンスへ分かれます。
- **説明書**: 設計目的、成果目的、利用目的に沿う標準操作を案内します。根拠なく変則的な使い方まで禁止しません。
- **教本**: 手順だけでなく、なぜその設計を選ぶかを学ぶ文章です。Q Atlantisの目的に必要な神話、信仰、
  哲学、形而上学を工学の飾りとして削りません。
- **資料**: 判断や研究の材料です。一次記録、異説、形而上学上の立場を、出所と棚を保って置けます。
- **リファレンス**: API、スキーマ、状態、対応表等を引く客観的な参照面です。単なる道具として示す箇所では、
  読者へ利用目的や信仰を推奨しません。

形而上学上の目的を拘束する文書では、雰囲気だけで普遍化せず、対象World、制定者、適用範囲、
事実・解釈・仮説、退出や分岐の条件を示します。逆に、形而上学が不要な機械リファレンスへ
世界観を強制注入しません。

## 安全を書く媒体を分ける

- 高出力、分かりにくい挙動、危険性を説明するだけなら、ドキュメントまたはリファレンスに置きます。
- 「用途に応じた安全は利用者自身が設計する」と案内する場合も、必要な設計点を示すドキュメントまたは
  リファレンスであり、製品保障ではありません。
- 契約上または契約保障上の安全、製品が引き受ける形而上学価値、責任を負えないため禁止する操作は、
  対象、利用目的、保障範囲、責任主体を明示した製品資料または製品説明書に置きます。

危険性の説明だけから禁止を生成せず、禁止を書く場合は製品責任、authority、適用範囲、例外条件へ接続します。

製造者へ用途外まで無限責任を負わせると、利用者が自分の安全設計を放棄するモラルハザードと
カスタマーハラスメントを生みます。逆に、責任回避のため人間を機械の標準用途へ従属させると、
機械に使われる人間を生産する支配設計になります。どちらもQ Atlantisの工学倫理に反します。

製品保障、客観的な危険説明、利用者が行う用途別安全設計、製品側の禁止authority、別設計・fork・退出経路を
分けます。「ネオナチ／メサイアコンプレックス／ターミネーター」は支配構造への強い警報比喩であり、
人物の病理、政治所属、犯罪性を診断する語として使いません。

## 公開前の確認

1. 英字は演出、固有名、機械境界、互換性のために必要か。
2. 一般概念を日本語または定着したカタカナへ戻せるか。
3. レンダー、GUI、画面、画面デザイン、目視確認を混同していないか。
4. スキーマー、スキーマ、`schema/`を役割どおりに書いたか。
5. 説明書、教本、資料、リファレンスを格付け語として使っていないか。
6. 工学を神話や信仰の裁判官として見せていないか。
7. 危険性の説明、利用者の安全設計、製品保障、契約上の禁止を混同していないか。
8. 海外テンプレートの媒体分類や免責定型を、日本語へ無監査で逆輸入していないか。
9. 製造者への無限責任または機械への人間従属を、安全設計として正当化していないか。
