# 奉納・協賛方法

Q AtlantisのPatronage Routerは、目的の違う資源を別の財布・責任・活動へ誤配線しないための入口です。公開テキストと受付条件のHuman review完了後、この入口からHIPSTAR保有のStripe決済ゲートへ接続します。

| route | 対象 |
|---|---|
| [物理で送りつける](./physical) | storage、compute、電材、工作・配信資材等の現物 |
| [HIPSTAR infrastructure](./hipstar-infra) | domain、hosting、power、storage、legal/IP等の研究炉基盤 |
| [餌付け](./feeding) | ふさもふ本人・関連communityへの物理送付、SFW／NSFW別wishlist、将来API棚 |
| [地域Commons](./commons) | 置賜郡射程の文化保護NPO・地域活動への既存導線 |

[物理で送りつける](./physical)routeにはoperator指定の公開受取先を掲載しています。新しい決済と振込口座は現時点で未実装です。これは決済非対応の宣言ではなく、テキスト確定前に課金を開始しないための公開Gateです。接続する決済ゲートはHIPSTARの会社資産であり、齋藤みつる個人の決済口座・個人資産ではありません。
