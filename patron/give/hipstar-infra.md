# HIPSTAR infrastructure

このrouteは、Q Atlantis／HIPSTARの通信塔と研究炉を維持する資源を扱います。

- Domain / Hosting
- Power
- Storage
- Compute
- Fabrication / Consumables
- Transport
- Legal / IP Counsel

地域Commons／NPOへの公開カンパとは別目的です。NPOがHIPSTARへ依存する構造も、HIPSTARがNPOの財布を吸い上げる構造も作りません。

新しい決済手段、銀行情報、継続課金は未実装です。operatorが公開用情報と受領主体を確認するまで、申込可能に見せません。
