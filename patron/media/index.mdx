# Media / Reach

Q Atlantis活動圏には技術、OSS、地域、祭、歌、配信、芸能、身体表現、SFW／NSFWが同時に存在します。
ここでは、その複数surfaceを企業SaaSの一枚絵へ縮約せず、観測できたmetricを定義付きで置きます。

<MediaMetrics />

掲載条件:

- platformとmetric名
- period
- `observedAt`
- 公開可能な`sourceRef`
- platform定義や集計上の注意

platform-reported impressionsをunique usersと呼びません。過去のviral hitをfuture minimum guaranteeとして販売しません。
