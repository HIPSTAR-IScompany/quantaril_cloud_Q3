# ⛩ Patron Ledger / 奉納台帳

ここは「あといくら足りないか」を叫ぶ募金メーターではありません。
Q Atlantis、HIPSTAR、ふさもふ活動圏へ、誰が、どの資源を、どのscopeで置いたかを運ぶ公開provenanceです。

<PatronLedger />

Q Atlantisは、現金、現物、輸送、場所、制作、現場協力を一つの金額scoreへ畳みません。
公式の金額順ranking、Gold／Silver／Bronze tier、「一番偉いPatron」は作りません。

公開記録に含めるのは、出典、対象、再掲範囲を確認できたrecordだけです。過去ソーシャルの感謝記録は
候補棚で検証し、読めた投稿を取引証明へ昇格させず、一件ずつ公開台帳へ移します。
