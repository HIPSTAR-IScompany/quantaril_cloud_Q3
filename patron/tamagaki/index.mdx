# 3DP Workbench 玉垣 / Tamagaki sponsorship

企業・団体名の物理名札を3DP Workbench横へ建立し、Web上の奉納台帳にも協賛広告として記録する構想です。

<PatronServiceStatus />

サービス開始前です。申込・決済はまだ受け付けていません。銘板の寸法、材質、固定方法、各termの物理枠数を調整しています。

開始前のフライング相談は、公式X（[@K_chachamaru](https://x.com/K_chachamaru)）のDMで受け付けます。相談だけで契約、受付順、枠の確保、支払義務は発生しません。カード番号、暗証番号、passwordはDMへ送らないでください。

<TamagakiCurrent />

## v0.1契約

- 1 termは6か月
- 更新Gateは夏越／大晦日
- 更新は自動ではなく、次termをあらためて申し込む
- term終了後はcurrent表示を終え、digital provenanceをarchiveへ残す
- 物理札はLabが制作・所有・設置し、v0.1では商品として発送しない
- 実際にplasticを焼却しない。退役、保管、再資源化を選ぶ
- 協賛広告であることを明瞭に表示する

[協賛広告policy](../policy/sponsorship)と[サービス開始前の特定商取引表示](../policy/commercial-transactions)を先に確認してください。物理寸法、材質、logo入稿条件、販売枠数は調整中です。
